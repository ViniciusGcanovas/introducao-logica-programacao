Sobre o curso

Curso introdutório destinado a estudantes iniciantes, desenvolvido para a disciplina de Pensamento Computacional. O objetivo é apresentar os conceitos fundamentais de programação utilizando Portugol Studio.

  • Algoritmos e lógica
  • Variáveis e tipos de dados
  • Entrada e saída
  • Operadores
  • Estruturas condicionais
  • Estruturas de repetição
  • Funções e procedimentos
