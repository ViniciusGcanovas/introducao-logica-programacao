# Introdução à Programação com Portugol

Projeto desenvolvido para a disciplina de **Pensamento Computacional**.

[**Acessar o site do projeto**](https://viniciusgcanovas.github.io/introducao-logica-programacao/)

## Objetivo

Apresentar conceitos básicos de programação utilizando Portugol.

## Conteúdos

- Algoritmos;
- Lógica de programação;
- Variáveis;
- Entrada e saída;
- Operadores;
- Estruturas condicionais;
- Repetições;
- Funções.

## Materiais

O projeto contém:

- Videoaula geral;
- Slides;
- Documento de apoio;
- Lista de exercícios;
- Projeto integrador.

Os materiais estão organizados no [site do projeto](https://viniciusgcanovas.github.io/introducao-logica-programacao/).

## Projeto final

Sistema simples de controle de notas e frequência.

### Funcionalidades

- Cadastro de estudante;
- Entrada de notas;
- Cálculo da média;
- Verificação da situação acadêmica.
